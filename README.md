# NoPauseVideoQuest

Keep Discord quest videos playing when you switch to another window.

## Install

1. Download [NoPauseVideoQuest.plugin.js](https://github.com/M0-kii/NoPauseVideoQuest/raw/refs/heads/main/NoPauseVideoQuest.plugin.js).
2. In Discord, go to **User Settings → BetterDiscord → Plugins → Open Plugins Folder**.
3. Put the downloaded file in that folder.
4. Enable **QuestBackgroundVideo** in the plugin list.

No extra plugins or setup needed.

## Use

Accept a video quest, open the trailer, and press **Play**. Leave the player open while you use another window. You can still pause the video or close it whenever you want.

The plugin only works on accepted video quests. It doesn't accept quests, skip videos, or claim rewards for you.

## Still seeing the away message?

Discord may show “We paused the video while you are away” even while the video keeps playing. Check the quest's progress counter. If it's still increasing, you can leave the video running. If progress stops, return to Discord and press **Resume**.

After updating the plugin, toggle it off and back on, then close and reopen the trailer. You can also open the plugin's settings and click **Refresh status** to check whether it found the quest video.

## Notes

Keep Discord running and your computer awake. Minimizing Discord may suspend playback.

While a quest player is active, the plugin makes Discord report its window as focused. Other features that use window focus may behave differently during playback. Disable the plugin to restore the usual behavior.

Discord updates can change how quest videos work, so playback and progress may need another check after an update.
